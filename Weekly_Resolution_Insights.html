Methodology. Every ticket closed as "Resolved By POC" or "Resolution Acknowledged" in the last 45 days (330 total) was graded against the resolution text (or worklog / acknowledgment text when no resolution was logged) using the same four-criterion rubric as the QA scorecard, each scored 1-5 by Claude. Grading was AI-assisted, not human-reviewed line by line — use the QA scorecard to spot-check agreement. Tickets with no resolution, worklog, or acknowledgment text on record are auto-scored low rather than skipped. "vs prior period" compares the current window to the equal-length period immediately before it (e.g., last 7 days vs the 7 days before that). Re-run this page on a fresh export to roll the window forward.
